NBS SOFT: сайт и инструкция (два файла, без сборки)

index.html : главный сайт NBS SOFT
help.html  : инструкция с фото (казахский и русский, озвучка)

Как выложить:
1. Загрузите оба файла в одну папку на любом хостинге статических сайтов (Netlify Drop, GitHub Pages, Cloudflare Pages, обычный хостинг).
2. Откройте адрес сайта. Главная страница index.html, ссылки между страницами уже настроены.
3. Свой домен подключается в настройках хостинга.

Внутри нет серверной части и не нужен PHP. Шрифты подгружаются с Google Fonts.
